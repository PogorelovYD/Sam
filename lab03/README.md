# Теоретическая часть

## Агрегатные функции

Агрегатные функции в SQL используются для выполнения вычислений над набором строк и возвращают одно итоговое значение.

В данной лабораторной работе применяются следующие агрегатные функции:

- `MAX()` — поиск максимального значения;
- `MIN()` — поиск минимального значения;
- `AVG()` — вычисление среднего значения;
- `SUM()` — вычисление суммы;
- `COUNT()` — подсчет количества строк.

## Группировка данных

Оператор `GROUP BY` используется для группировки строк по одному или нескольким столбцам. После группировки агрегатные функции применяются отдельно к каждой группе.

Пример логики работы:

```sql
SELECT
    column_name,
    AVG(value_column)
FROM table_name
GROUP BY column_name;
```

## Фильтрация групп

Для фильтрации обычных строк используется оператор `WHERE`.

Для фильтрации сгруппированных данных используется оператор `HAVING`.

Например, если нужно оставить только те группы, у которых сумма больше определенного значения, используется `HAVING`.

# Задание 1

## Условие

Найти разницу между самой дорогой и дешевой машиной.

## SQL-запрос

```sql
SELECT
    MAX(base_msrp) AS max_car_price,
    MIN(base_msrp) AS min_car_price,
    MAX(base_msrp) - MIN(base_msrp) AS price_difference
FROM products
WHERE product_type = 'automobile';
```

# Задание 2

## Условие

Посчитать среднюю цену продуктов для каждого года выпуска.

## SQL-запрос

```sql
SELECT
    year,
    ROUND(AVG(base_msrp)::numeric, 2) AS avg_product_price
FROM products
GROUP BY year
ORDER BY year;
```

## Скриншот результата

<img width="866" height="984" alt="Image" src="https://github.com/user-attachments/assets/0dc3d77b-5fb8-4d06-b262-f4f6d6ac9588" />

## Описание выполнения

В данном запросе данные из таблицы `products` группируются по году выпуска с помощью оператора `GROUP BY`.

Для каждого года рассчитывается средняя цена продукта с помощью агрегатной функции `AVG(base_msrp)`.

Так как в PostgreSQL при округлении числа типа `double precision` до двух знаков после запятой может потребоваться явное приведение типа, результат средней цены приводится к типу `numeric`:

```sql
AVG(base_msrp)::numeric
```

После этого используется функция `ROUND(..., 2)`, чтобы округлить среднюю цену до двух знаков после запятой.

Сортировка результата выполняется по году выпуска с помощью оператора `ORDER BY year`.

## Результат

В результате выполнения запроса была получена таблица, где для каждого года выпуска указана средняя цена продуктов.

# Задание 3

## Условие

Найти клиентов, чья суммарная сумма покупок больше 20,000.

## SQL-запрос

```sql
SELECT
    c.customer_id,
    c.first_name,
    c.last_name,
    ROUND(SUM(s.sales_amount)::numeric, 2) AS total_purchase_amount
FROM customers c
INNER JOIN sales s
    ON c.customer_id = s.customer_id
GROUP BY
    c.customer_id,
    c.first_name,
    c.last_name
HAVING SUM(s.sales_amount) > 20000
ORDER BY total_purchase_amount DESC;
```

## Скриншот результата

<img width="870" height="915" alt="Image" src="https://github.com/user-attachments/assets/82a7bfea-f418-4531-a3b9-8ad5d865f235" />

## Описание выполнения

В данном запросе таблица `customers` соединяется с таблицей `sales` с помощью `INNER JOIN`.

Соединение выполняется по общему полю `customer_id`:

```sql
ON c.customer_id = s.customer_id
```

После соединения данные группируются по каждому клиенту:

```sql
GROUP BY
    c.customer_id,
    c.first_name,
    c.last_name
```

Для каждого клиента рассчитывается суммарная сумма покупок с помощью агрегатной функции:

```sql
SUM(s.sales_amount)
```

Чтобы в результате не отображалось слишком много цифр после запятой, используется округление до двух знаков:

```sql
ROUND(SUM(s.sales_amount)::numeric, 2)
```

Приведение к типу `numeric` необходимо, так как в PostgreSQL функция `ROUND` с двумя аргументами не применяется напрямую к типу `double precision`.

Фильтрация клиентов выполняется с помощью оператора `HAVING`:

```sql
HAVING SUM(s.sales_amount) > 20000
```

Это условие оставляет только тех клиентов, у которых суммарная сумма покупок больше `20,000`.

Сортировка выполняется по суммарной сумме покупок в порядке убывания:

```sql
ORDER BY total_purchase_amount DESC
```

## Результат

В результате выполнения запроса были найдены клиенты, сумма покупок которых превышает `20,000`.
