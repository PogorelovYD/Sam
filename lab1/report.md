# Задания

## Задание 1.1: Продавцы (salespeople) с именем 'William'

Модернизация запроса:
1. Сортировка по дате найма (hire_date) установлена от самой ранней к самой поздней (ASC).
2. Выведены все атрибуты (SELECT *) для полного анализа профиля продавца, включая пол и идентификатор.

Скрипт для выволнения запроса:

```sql
SELECT * 
FROM salespeople 
WHERE first_name = 'William' 
ORDER BY hire_date ASC;
```

## Задание 1.2: Работа с товарами (products) в ценовом диапазоне.

Условие: Получите список товаров (products), цена которых находится в пределах от 1000 до 2000.

Модернизация запроса:  
1. В связи с особенностями структуры используемой БД, поле «цена» идентифицировано как base_msrp.
2. Использован оператор BETWEEN для оптимизации условий выборки.
3. Добавлена сортировка по убыванию цены для наглядности результатов.

Скрипт для выволнения запроса:

```sql
SELECT product_id, model, base_msrp, production_start_date 
FROM products 
WHERE base_msrp BETWEEN 1000 AND 2000 
ORDER BY base_msrp DESC;
```

## Задание 1.3: Маркетинговые операции (CRUD) — Таблица west_dealers
Условие (Среда: Локально):

1.Создание. Создайте таблицу west_dealers, скопировав данные дилеров из штатов WA, OR, CA.

2.Изменение. Добавьте текстовый столбец zone.

3.Обновление. Заполните столбец zone значением 'West'.

4.Удаление. Удалите из новой таблицы записи о закрытых дилерских центрах.

Модернизация запроса: 
1. Для удаления использована колонка date_closed (согласно системному каталогу таблицы dealerships).
2. Условие удаления базируется на наличии даты закрытия (IS NOT NULL), что гарантирует актуальность итогового списка.

Скрипт для выволнения запроса:

```sql
-- 1. Создание таблицы на основе фильтра по штатам
CREATE TABLE west_dealers AS 
SELECT * FROM dealerships 
WHERE state IN ('WA', 'OR', 'CA');

-- 2. Добавление нового атрибута
ALTER TABLE west_dealers ADD COLUMN zone TEXT;

-- 3. Массовое обновление данных
UPDATE west_dealers SET zone = 'West';

-- 4. Очистка таблицы от закрытых центров
DELETE FROM west_dealers 
WHERE date_closed IS NOT NULL;

-- Проверка итогового состояния таблицы
SELECT * FROM west_dealers;
```
